# Smartlead Campaign Reply Email Notifier

A python script & webhook server that monitors **Smartlead campaign replies** in real time and automatically forwards email notifications with full lead & reply details to **multiple recipient emails**.

---

## 📁 Project Structure

```
smartlead_reply_notifier/
├── config.py              # Loads and parses environment variables
├── notifier.py            # Email formatter (HTML/Text) & SMTP dispatch engine
├── server.py              # Flask Webhook endpoint listener for Smartlead
├── list_campaigns.py      # Helper CLI to fetch & view all Smartlead Campaign IDs
├── test_webhook.py        # Test script to simulate reply events locally
├── .env.example           # Environment configuration template
└── README.md              # Instructions & documentation
```

---

## 🛠️ Step-by-Step Setup Instructions

### 1. Copy Environment Configuration

Create a `.env` file from `.env.example`:
```bash
cp .env.example .env
```

### 2. Configure `.env` Settings

Edit `.env` and fill in your details:

```env
# Your Smartlead API Key (Find in Smartlead -> Settings -> API Keys)
SMARTLEAD_API_KEY=your_smartlead_api_key

# Target Campaign ID to listen for (Use list_campaigns.py to find it)
CAMPAIGN_ID=123456

# Recipients who will receive reply email alerts (comma-separated list)
RECIPIENT_EMAILS=alice@company.com,bob@company.com,charlie@company.com

# SMTP Settings for email delivery (e.g. Gmail App Password)
SMTP_HOST=smtp.gmail.com
SMTP_PORT=587
SMTP_USER=your_email@gmail.com
SMTP_PASSWORD=your_gmail_app_password
SENDER_EMAIL=your_email@gmail.com
SENDER_NAME=Smartlead Reply Notifier

# Server Port
WEBHOOK_PORT=5000
```

> **Note for Gmail Users**: Use an [App Password](https://myaccount.google.com/apppasswords) for `SMTP_PASSWORD` instead of your regular password.

---

### 3. List Your Smartlead Campaigns

To easily find your `CAMPAIGN_ID`, run:
```bash
python list_campaigns.py
```
This outputs a table of all your campaigns:
```
================================================================================
CAMPAIGN ID     | STATUS     | REPLIES    | CAMPAIGN NAME
================================================================================
123456          | ACTIVE     | 14         | Enterprise Q3 Cold Outreach
789012          | DRAFT      | 0          | SMB Founder Outreach
================================================================================
```
Copy the ID of the campaign you want to monitor and set `CAMPAIGN_ID=123456` in your `.env`.

---

### 4. Run the Webhook Server

Start the webhook server:
```bash
python server.py
```
You should see:
```
Starting Smartlead Webhook Listener on 0.0.0.0:5000
Monitoring Campaign ID: 123456
Notifying Recipients: ['alice@company.com', 'bob@company.com', 'charlie@company.com']
```

---

### 5. Expose Webhook URL to Smartlead

For Smartlead to send events to your server:

#### Local Testing (using `ngrok`):
```bash
ngrok http 5000
```
Copy the HTTPS URL generated by ngrok (e.g., `https://abc1234.ngrok-free.app`). Your full webhook URL is:
`https://abc1234.ngrok-free.app/webhook/smartlead`

#### Production Deployment:
Deploy `server.py` on your cloud server (e.g., AWS EC2, DigitalOcean, Railway, Render) and use its public URL/domain.

---

### 6. Register Webhook in Smartlead

1. Log into **Smartlead.ai**.
2. Go to your campaign -> **Campaign Settings** -> **Webhooks**.
3. Click **Add Webhook**.
4. Set **Event**: `Email Reply` (or `Lead Reply`).
5. Enter **URL**: `https://your-domain-or-ngrok.app/webhook/smartlead`.
6. Save the webhook.

---

### 7. Test Locally

With `python server.py` running in one terminal, open another terminal and run:
```bash
python test_webhook.py
```
This will send a simulated Smartlead reply payload to your server. If your SMTP credentials are correctly set, all `RECIPIENT_EMAILS` will immediately receive an alert email! 📬
